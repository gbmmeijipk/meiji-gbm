# GLOBAL BRANDS MARKETING (PVT) LTD. — Website

A responsive, trilingual (English / Japanese / Urdu) corporate website starter for the marketing, sales and distribution of MEIJI products in Pakistan.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser, or run a local static server from this folder:
   - Python: `python -m http.server 8000`
   - Then visit `http://localhost:8000`

## Important notes
- The contact form prepares an email in the visitor's email application. It does not send or store submissions on a server.
- WhatsApp integration is not enabled because an official WhatsApp number was not supplied.
- News, distribution coverage and company history sections are intentionally generic until verified company information is provided.
- Product descriptions are intentionally limited. Always use approved, current MEIJI product information and packaging. Infant and child feeding decisions should follow product labels and qualified healthcare professional advice.
- Google Fonts are loaded from Google Fonts when an internet connection is available. System fallbacks are included.
- Confirm rights and approval for all logos, product photographs and brand assets before public deployment.

## Main files
- `index.html` — single-page corporate website
- `css/style.css` — main styling
- `css/responsive.css` — responsive breakpoints
- `js/translations.js` — English, Japanese and Urdu text
- `js/main.js` — language selector, navigation, form and UI behavior
